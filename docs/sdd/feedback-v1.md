# Отзыв участника преподавателю v1

Решение владельца от 11.11.2026: команда обратной связи означает отзыв студента
преподавателю проекта, а не результат оценки 4К. Преподаватель в текущей модели —
активный администратор, создавший проект.

`/feedback PROJECT_CODE` работает в личном чате после принятия приглашения.
Бот проверяет активное участие в проекте до запроса текста и непосредственно перед
отправкой. Следующее текстовое сообщение длиной 1–3000 символов отправляется
создателю проекта через Telegram Bot API с кодом проекта и именем участника.
`/cancel` отменяет ввод. Содержимое не сохраняется в БД и не отправляется в 4К.

При ошибке Telegram Bot API доставка не подтверждается и автоматический повтор
не выполняется: повтор может создать дубль, если первоначальная отправка дошла.
Участник получает предложение уточнить доставку у преподавателя.

Граница: журнал отзывов, вложения, анонимность, пересылка нескольким преподавателям
и гарантированная доставка не реализованы. До выпуска проверить Telegram-путь
с тестовыми учётными записями. Откат — вернуть код команды и меню; данные и схема
не меняются.
