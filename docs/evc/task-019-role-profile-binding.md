# TASK-019: отдельное сопоставление учебной роли с профилем оценки 4К

## Результат

Учебная роль и её назначение студенту больше не требуют редактирования после
подключения оценки. В боте публикуется отдельная версия сопоставления с
`RoleProfileVersion` 4К, проверенная по read-only API. Новое назначение оценки
закрепляет точный ID этой версии; прежние назначения и snapshots не меняются.
Внешний snapshot v1 для 4К сохраняет прежнюю схему и поля.
